# 情報圧縮メモ生成スキル

既にあるコンテンツを、次工程（図解コンテンツ生成）のソースになる圧縮メモに変換するスキル。

このスキルの肝は **「接続詞で論理を見せる文章」のまま圧縮する** こと。構造化ラベルを付けて要素分解するのではなく、文章として読めば因果・流れ・温度感が伝わる形で出力する。これにより、次工程の図解化AIが「どこを切り取るか・どこを矢印で結ぶか」を自分で判断できる。

---

## このスキルが発動する条件

以下のキーワードがあれば発動する：

- 「これを情報メモにして」「圧縮メモにして」「ギュッとまとめて」
- 「図解の元にして」「図解コンテンツの元になるメモを作って」
- 「この記事を1枚ずつにまとめて」「複数枚分のメモにして」
- 既にあるコンテンツ（記事・知識・調べたメモ）を渡されて「メモ化」「要点圧縮」と指示されたとき

---

## 入力仕様

ユーザーが **複数枚分のメモがまとまったテキスト** を渡す前提で動く。

- 1枚=1トピックの境界は、明示区切り（`---` / 見出し / 番号）と話題転換が混在することがある
- 入力テキストにない情報は補完しない（捏造防止ルールを参照）
- テーマだけ渡された場合は「もとになるテキストをください」と返す

---

## 処理フロー（2段階）

```
入力（複数枚分のテキスト）
  ↓
Step 1: 分解（1枚=1トピックに切り出す）
  ↓
Step 2: 各1枚の圧縮処理
  ↓
出力（N枚分の圧縮メモ）
```

### Step 1: 分解の判定基準

入力テキストから1枚=1トピックの境界を見つける。明示区切りと話題転換のAI判定を併用する。

- **明示区切り**：`---` / `===` / 見出し（`# / ## / ###` / 「タイトル：」）/ 番号（`1.` / `①` / 「一、」）
- **話題転換**：明示区切りがなくても主語・テーマが大きく変わったら境界とみなす
- 判定が曖昧なときは **少なめに分解** する（過剰分割より結合の方が修正しやすい）

### Step 2: 各1枚の圧縮処理

各1枚に対して以下の手順を順に実行する：

1. 元メモの段落構造・章順序をそのまま保つ（3段落なら3段落、2段落なら2段落、5段落なら5段落で出力）
2. 元メモのジャンルを判定する（後述の「ジャンル別マッピング」を参照）
3. ジャンルに対応する「保持する要素」を抽出し、圧縮後も文章の中に残す
4. 共通規格（後述）を満たす形に短く書き直す
5. 元メモに章構成のヒントがないときは、情報の流れに応じて構成を選ぶ

---

## 1枚あたりの共通規格（接続詞で論理を見せる文章）

ジャンルを問わず守ること：

1. **接続詞で論理を見せる文章で書く**：「実は」「ではどこで」「だから」「つまり」「しかも」「一方で」などで因果・対比・並列を可視化する
2. **段落で論点を区切る**：1段落=1つの論点・問い・場面
3. **元メモの核（伝えたい本質）を落とさない**
4. **無駄な言葉を削って情報密度を上げる**
5. **元メモの温度感を保つ**：熱量が高ければ熱量を保ち、淡々としていれば淡々と。元になければ足さない
6. **字数目安：400字前後**（1枚で読める量に圧縮）
7. **構造化ラベル（【主張】【根拠】など）は使わない**：文章のまま接続詞で論理を見せる

---

## ジャンル別マッピング（保持要素・トーン・接続詞）

骨格は共通（接続詞で論理を見せる文章）。ジャンルで変わるのは「保持する要素」「トーン」「使う接続詞の傾向」の3点。

| 元メモのジャンル | 保持する要素 | トーン | よく使う接続詞 |
|---|---|---|---|
| ビジネス分析・市場ネタ | 規模の数字・比較・因果 | 熱量あり | 「実は」「ではどこで」「しかも」「だから」 |
| 体験談・エッセイ | 感情・転換点・気づき・情景 | 感情ベース | 「あの時」「気づいた」「だから今は」 |
| 学術・概念解説 | 定義・構造・具体例・専門用語 | 抑えめ・論理的 | 「すなわち」「したがって」「逆に」「ここで重要なのは」 |
| ニュース解説 | 5W1H・影響範囲・時系列 | 客観 | 「現時点で」「これにより」「ただし」「今後は」 |
| ノウハウ・How-to | ステップ・条件・例外・実例 | フラット | 「まず」「次に」「ただし」「具体的には」 |
| 主張・意見 | 論点・根拠・反論対応 | 主張に応じて | 「なぜなら」「とはいえ」「だからこそ」「逆に言えば」 |

ジャンル判定が曖昧なときは、元メモが既に持っている要素・トーン・接続詞をそのまま保持する。

---

## タイトル設計

元メモにタイトルがあればそれをベースにする。タイトルの語感はジャンルに合わせる。

| ジャンル | タイトルの型 | 参考例 |
|---|---|---|
| ビジネス分析 | 主体 + 意外な何か | 「コストコが儲けるヤバい理由」 |
| 体験談 | 主語 + 経験 | 「20kg痩せて分かったこと」 |
| 学術解説 | テーマの問い | 「複雑系とは何か」 |
| ニュース解説 | 事実 + 論点 | 「ハンタウイルス感染拡大、何が起きているか」 |
| ノウハウ | 行動 + 結果 | 「30日でアウトプットを倍にする方法」 |
| 主張・意見 | 主張 + 含意 | 「いま読書が必要なたった一つの理由」 |

※あくまで参考例。テーマやジャンルに応じて適宜書き換えること。

---

## 参考例（コストコ1枚分・正解形）

```
タイトル：コストコが儲けるヤバい理由

コストコは世界で900店舗以上、会員は約1.4億人、売上は約40兆円という巨大企業。実はこの会社、商品ではほとんど利益を出していない。スーパーの粗利が20〜30％なのに対し、コストコは約10％前後。つまり商品はほぼ原価に近い価格。

ではどこで儲けているのかというと「年会費」。数千円の会費を世界中の会員が払うため、それだけで巨大な利益が生まれる仕組み。しかも会員制なので売上が安定し、顧客は「会費を払ったから行こう」と通い続ける。

コストコの利益を出す秘密→「商品数が少ない、スーパーが5万商品、コストコは4000商品」「店舗はほぼ倉庫でコストを削減」「広告をほぼ出さずに口コミで拡散」「巨大サイズで販売で平均客単価1.5万円以上」「平均店舗売上は300億円でスーパーの10倍」
```

この見本がフォーマットの **正解形**：
- 接続詞（「実は」「ではどこで」「しかも」「だから」）で因果が文章に埋め込まれている
- 数字も文中に自然に組み込まれている（箇条書きの羅列にせず、文として読める）
- 段落で論点が区切られている（規模＋意外性 → 核心の謎解き → 詳細の畳みかけ）
- 装飾は元の温度感の範囲内で、過剰な煽りは入っていない

骨格はジャンルに関わらずこの形（接続詞で論理を見せる文章）。ジャンルでトーン・使う接続詞・保持する要素が変わる。

## 捏造防止ルール

入力テキストにある情報だけを使う。AI側で補完しない。

### 禁止事項

- 入力テキストにない数字を加える
- 入力テキストにない事実・名前・年代を加える
- 「〇〇大学の研究では」「〇〇という論文によると」のような出典の創作

### 推奨フレーズ（不明・曖昧なとき）

- 数字が不明 → 「数百〜数千」「〇〇規模」「多くの」
- 出典が不明 → 「一般に言われている」「〜という考え方が知られている」
- 確証が薄い → 「目安として」「およそ」

### 名言・引用の扱い

- 入力テキストにある引用のみそのまま使う
- 入力にない名言を補完して足さない

---

## 修正指示の受け方

一発生成後、ユーザーが指示を出したら該当部分だけ書き直す：

| 指示の例 | 対応 |
|---|---|
| 「3枚目のタイトル弱い」 | 該当する1枚のタイトルだけ再生成 |
| 「全体的に数字入れて」 | 全枚で数字を補強（入力テキストにあるもののみ） |
| 「2枚目を分けて」 | 該当する1枚をさらに分解 |
| 「1枚目と4枚目をくっつけて」 | 該当2枚を結合 |
| 「もう少しフラットに」 | 全枚または指定枚のトーンを抑えめに調整 |

---

## 出力形式

- プレーンテキストで出力（コピペしやすい形）
- HTML Artifactは使わない（次工程の図解化スキル等に流すため、テキスト形式が望ましい）
- 各1枚は太い区切り（`========================================`）で明確に分離
- 各1枚の冒頭に `【1枚目】` `【2枚目】` のラベルを付ける
- 1枚の中の段落構造は元メモのまま尊重し、構造化ラベルは付けない

### 出力イメージ

```
========================================
【1枚目】
タイトル：コストコが儲けるヤバい理由

（本文：元メモの段落構造に従った文章）

========================================
【2枚目】
タイトル：〇〇

（本文：元メモの段落構造に従った文章）

========================================
【3枚目】
（以下同様）
```

## コンテンツ品質チェックリスト

完成出力を返す前に確認する。

### 内容の正確さ
- [ ] 入力テキストにない数字・事実・名前を加えていないか
- [ ] 出典を創作していないか
- [ ] 不明な情報は曖昧表現（「数百〜数千」「目安として」など）になっているか

### 文章の質
- [ ] 接続詞で因果・対比・並列が見えるか
- [ ] 段落が論点ごとに区切られているか
- [ ] 一文が長すぎないか（目安：50字以内が中心）
- [ ] 元メモの良さ（流れ・温度感）が保たれているか

### 形式
- [ ] 各1枚が太い区切りで分離されているか
- [ ] 各1枚の冒頭に番号ラベルが付いているか
- [ ] 構造化ラベルが入っていないか
