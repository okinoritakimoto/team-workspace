# このプロジェクトについて

複数フォーマットのSNS投稿（コミックスライド、早口構文など）のコンテンツ・プロンプトを作成するプロジェクト。

## ディレクトリ構成

- `ネタリスト.md` — 投稿ネタのストック管理（ステータス：🌱ストック / ✍️制作中 / ✅投稿済み）。フォーマットを問わず全ネタをここで一元管理する
- `コミックスライド投稿一覧/` — コミックスライド形式（画像生成プロンプト）の完成投稿を格納する場所
  - `見本/` — レイアウト・デザイン設計のテンプレート見本（例: `コミックスライド見本a.md`, `コミックスライド見本b.md`）。参照専用で、内容は書き換えない
- `早口構文投稿一覧/` — 早口構文形式（テキスト投稿）の完成投稿を格納する場所
  - `見本/` — 文体・構成のテンプレート見本（例: `examples.md`）。参照専用で、内容は書き換えない
- `.claude/skills/` — `comic-slide-post` / `contents-craft` / `info-slide` などのスキル定義
- 今後フォーマットが増える場合も `〇〇投稿一覧/` + `見本/` の構成に揃える

## 投稿ファイルの命名ルール

各`〇〇投稿一覧/` 直下に保存する投稿ファイルは、**作成日を基本にして命名する**。

```
YYYY-MM-DD_ネタ名.md
```

例: `コミックスライド投稿一覧/2026-07-22_熱中症対策.md`、`早口構文投稿一覧/2026-07-22_ヒートショック.md`

- 日付はそのファイルを新規作成する当日の日付を使う
- 同じ日に複数の投稿を作る場合は末尾に連番を付ける（例: `2026-07-22_熱中症対策_2.md`）
- `見本/` 配下のテンプレートファイルはこの命名ルールの対象外

## 投稿作成時の遵守事項

フォーマットを問わず、投稿のプロンプト/原稿ファイルを新規作成・保存する際は、必ず上記の命名ルールに従うこと。既存の`見本/`ファイルの構成・文体・デザイン設計は変更せず、内容部分だけを新しいネタに差し替える。
