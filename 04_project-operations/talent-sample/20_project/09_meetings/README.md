# 09_meetings — 会議体（場）の定義と、開催1回ごとの記録

> **30秒**: 「場」（毎週の運転会議・月次点検・重要意思決定の場・臨時）は `bodies/` に1場1ファイルで定義し、
> 開催1回は `MTG-talent-sample-<YYYYMMDD>.md` に1回1ファイルで残す。**⓪（前回の検収）を飛ばした瞬間に形骸化が始まる**。

```text
09_meetings/
├─ bodies/<場のキー>.md        場の定義（目的・決められること・リズム・入力・出力）。weekly.md は最初から置いてある
├─ MTG-talent-sample-<YYYYMMDD>.md   開催1回1ファイル（種別ごとの雛形を複製）
└─ operation_rules.md          会議で決めた運転上の約束（軽量）
```

## 雛形（複製して使う）

### まず作る3本（発足〜初回会議までに要るのはこれだけ）

| 種別 | 雛形 | いつ |
|---|---|---|
| 場の定義 | [bodies/weekly.md](bodies/weekly.md)（**最初から置いてある**。埋めるだけ） | 運転開始前に1回（weekly を必ず） |
| キックオフ | [_kickoff_template.md](_kickoff_template.md) | 発足直後・計画がまとまったら1回 |
| 週次運転会議（⓪〜⑥） | [_meeting_template.md](_meeting_template.md) | 毎週月曜 09:00〜10:00（サンプル） |

### 後で作る3本（必要になった時に開けばよい。最初の月は読まなくてよい）

| 種別 | 雛形 | いつ |
|---|---|---|
| 月次点検 | [_monthly_check_template.md](_monthly_check_template.md) | 月初・60〜90分（最初の月初から） |
| 重要意思決定の場 | [_decision_forum_template.md](_decision_forum_template.md) | ベースライン（範囲・期限・予算）に触れる時だけ・承認者必須 |
| 臨時 | [_ad_hoc_template.md](_ad_hoc_template.md) | 必要時。ベースラインはここで決めない |

> **記入のコツ**: 会議録は⓪から順に**上から埋めながら**進める（会議のあとで清書しない）。
> ④の表が埋まって初めて会議が終わります（担当1人・期限・完了の定義・起票IDの4つが1行にそろう）。
> 実データを入れるときは、この見本2件を消してから使います。

## 記録の境界（守る）

- 録音・文字起こし・私的メモは **Git に入れない**（`.local/` か先方の規程に従う場所）。ここに置くのは、決めたこと・数字・タスク・気づきだけ。
- 開かなかった会議の架空の記録を作らない。開けなかったら次回の⓪で「前回未開催」と1行残す。
- 会議中に出た変更の言い出しは [11_change_log.md](../11_change_log.md) へ、決定は [05_decision_log.md](../05_decision_log.md) へ、詰まりは [07_issue_ledger.md](../07_issue_ledger.md) へ、**会議が終わる前に**。

## 法則

- **≡ 帳（追記だけ）** — 過去の会議録を書き換えない。訂正は次回の⓪で。`bodies/` の定義は ▤（合意で変わる）。
