# 09_meetings/bodies — 場（会議体）の定義

> **30秒**: 会議の「場」を1場1ファイルで定義する。**`weekly.md`（週次運転会議）は最初から置いてあります — 埋めるだけ**。
> 他の場が要るようになったら `_body_template.md` を複製し、表の値を埋めます。

| 場のキー | いつ作るか | いまの状態 |
|---|---|---|
| [weekly.md](weekly.md) | 運転開始前に必ず（毎週月曜 09:00〜10:00（サンプル）） | **最初から置いてある**（見本入り・書き換える前提） |
| `monthly.md` | 最初の月次点検の前に | まだ無い（`_body_template.md` を複製して作る） |
| `decision-forum.md` | 最初のベースライン変更の言い出しが出た時に | まだ無い（同上） |
| `kickoff.md` / `ad-hoc.md` | 必要なら（1回きりなら weekly の場で開いてよい） | まだ無い（同上） |

> **記入のコツ**: `weekly.md` で最初に決めるのは **曜日・時刻・進行役・必ず出る人**の4つ。ここが決まらないと運転が始まりません。
> **状態**（`draft` / `pilot` / `active` / `retired`）は英語の値で書きます。1回でも定期で開いたら `active` へ。

## 法則

- **▤ 棚（合意で変わる）** — 場の目的・決められること・リズムを変えるのは会議の合意で。
- **空箱禁止** — `weekly.md` は運転開始と同時に埋まっている。他の場は、必要になった日に作る。
