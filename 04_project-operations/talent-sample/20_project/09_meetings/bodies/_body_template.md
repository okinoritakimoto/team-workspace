# <場の名前>（`bodies/<場のキー>.md` へ複製）

> 場の定義は1場1ファイル。場のキーは英小文字・数字・ハイフン（例: weekly / monthly / decision-forum / ad-hoc / kickoff）。
> 場の識別は「このプロジェクト＋場のキー」。新しいIDの体系は作らない。

| 項目 | 記入欄 |
|---|---|
| 場のキー | weekly |
| 表示名 | 週次運転会議 |
| 種別 | 週次 / 月次点検 / 重要意思決定 / 臨時 / キックオフ |
| 目的 | 事実（数字）を見て、原因と施策を話し、アクションを決めてタスクにする |
| ここで決められること | 運転上のアクション（ベースライン変更は決めない → 重要意思決定の場へ） |
| リズム・時間 | 毎週月曜 09:00〜10:00（サンプル）・60分 |
| 進行役 | PM（サンプル） |
| 必ず出る人 | PM（サンプル）・各WPのリード |
| 出てほしい人 | リーダー（サンプル）（月1回以上） |
| 入力（会議前に揃っているもの） | `20_project/03_dashboard.md`（更新済み）・前回の④で決めたタスクの状態 |
| 出力（会議が終わる時にあるもの） | タスク（`04_tasks/`）・決定（`05_decision_log.md`）・課題（`07_issue_ledger.md`）・変更受付（`11_change_log.md`）・次回議題 |
| 議事の雛形 | `../_meeting_template.md` |
| 状態 | `draft`（案） |
| 次回 | YYYY-MM-DD HH:MM |

**状態の欄には英語の値を書く**（日本語は読むための言い方）。支援側の元の型と同じ値をそのまま使い、言い換えで食い違わないようにする。

| 書く値 | 読み方 | いつ |
|---|---|---|
| `draft` | 案 | 場を作ったばかり。まだ開いていない |
| `pilot` | 試行 | 数回開いて、形を試している |
| `active` | 運転中 | 定期で回っている |
| `retired` | 終了 | この場は開かない（行は消さず状態だけ変える） |

## 健全性（この場が機能しているか・月次点検で見る）

| 指標 | 出し方 | 目安 |
|---|---|---|
| 決定がタスクになった割合 | タスク化された決定 ÷ 会議の全決定 | 100%（下がったら「後で割り振り」が起きている） |
| 実行率 | 完了 ÷ 期限到来 | 週次で見る。分母0なら「対象なし」と書き100%にしない |
