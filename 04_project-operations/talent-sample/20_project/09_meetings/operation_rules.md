# operation_rules — 会議で決めた運転上の約束（軽量）

> 会議の運転の仕方について決めた約束だけを記録する（例: 「計器盤は日曜までに更新」「⓪は必ず10分」）。`次の見直し` は必須。
> 自動実行・優先順位の計算はこの表の役割ではない。

> **▼ 下の1行は見本データ（サンプル）です。書き換える前提**で置いてあります。
> **記入のコツ**: 「〜を心がける」は約束になりません。**時間・締切・回数**のどれかが入る形で書きます。

| 内容 | 対象 | 理由 | 決めた会議 | 有効開始 | 状態 | 次の見直し |
|---|---|---|---|---|---|---|
| ⓪（前回の検収）に必ず10分取る | 週次運転会議 | ⓪を飛ばすと決めたことが追われなくなる | [MTG-talent-sample-20260828.md](MTG-talent-sample-20260828.md) | 2026-08-31 | `trial`（試行） | 2026-09-28（月次点検） |
| ─ | ─ | ─ | ─ | ─ | ─ | ─ |
| | | | MTG-talent-sample-… | | `candidate`（候補） | |

> `─` の行は**見本と記入用の境目**です。実データに差し替えるときは、上の見本1行を消してから使います。

## 状態の4つ（書く値は英語・読み方は日本語）

**状態の欄には左の「書く値」を書く**。日本語は読むための言い方で、値ではない。
これは支援側の元の型と同じ値をそのまま使うため — 将来この記録を機械で読む時に、言い換えの分だけ食い違うのを防ぐ。

| 書く値 | 読み方 | いつ |
|---|---|---|
| `candidate` | 候補 | 決めたばかり。まだ試していない |
| `trial` | 試行 | お試し中。次の見直しで判定する |
| `continue` | 継続 | 効いたので続ける |
| `revoke` | 廃止 | 効かなかった・要らなくなった（行は消さず状態だけ変える） |
