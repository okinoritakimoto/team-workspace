# 03 AIを使った商品開発

AIを活用した新サービス・商品のアイデア・調査・プロジェクトを管理するフォルダです。

## ファイル一覧

| フォルダ | 内容 |
|---|---|
| `ideas/` | アイデア・企画メモ |
| `research/` | AI技術・ツール調査レポート |
| `projects/` | 実際に進行中の開発プロジェクト |

## 使い方

- アイデアが浮かんだら `ideas/` にメモを追加
- 使えそうなAIツールを調べたら `research/` にレポートを追加
- 具体的に動き出したら `projects/` にプロジェクトフォルダを作成
