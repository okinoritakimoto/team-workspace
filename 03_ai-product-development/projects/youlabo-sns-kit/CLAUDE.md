## 2. フォルダ構成

| フォルダ | 置くもの |
|---|---|
| `research/` | 調べた結果（市場・競合・顧客の声・売れている商品）。出典つき |
| `knowledge/` | 決めたこと・蓄積する素材（`concept/`・文体集・見本投稿・キラーワードなど） |
| `rules/` | 判断基準・好み・避ける表現 |
| `posts/` | 発信の設計（トピッククラスター・フック・ネタ・型） |
| `analysis/` | 投稿の結果の分析 |
| `products/` | 商品（`note/`＝低単価、`high-ticket/`＝高単価） |
| `promotion/` | ローンチ・販売用の投稿 |
| `funnel/` | 導線・LINE・VSL・個別相談・セミナー |
| `.claude/skills/` | スキル化した作業 |
